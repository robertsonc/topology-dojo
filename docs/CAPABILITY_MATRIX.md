# Capability Matrix — Topology Dojo

_Compiled 2026-07-19 and revalidated 2026-08-09 against `main` at `4add174`
(not from prior docs). Initiative A rows added 2026-08-19. On 2026-11-13,
against `main` at `e99b012`, every evidence citation was re-resolved (stale
line numbers replaced by the file and symbol they pointed at), the rows for
work shipped since August were added, and the deployment and MCP-inventory
rows were corrected; the remaining row statuses were not re-audited end to
end. Every row cites the code evidence used to classify it.
Classifications:_

- **Shipped-active** — in code, exercised by tests, and live in the current production config (`wrangler.jsonc` top-level).
- **Shipped-behind-flag** — in code and tested, but the flag mechanism is opt-in/opt-out; noted whether the CURRENT production value is on or off.
- **Partial** — real code exists but a documented sub-claim is unmet (e.g., one call site missing a fix applied elsewhere).
- **Documented-not-implemented** — a doc or code comment claims this exists; it does not.
- **Operationally pending** — the code/infrastructure is shipped; a human action outside the repo (a dashboard setting, a drill, a credential) is still required.
- **Deferred / does-not-exist** — no code, intentionally not built yet.

This matrix is the evidentiary basis for `docs/ROADMAP.md`'s "Current Production Baseline" and for `docs/DISCREPANCY_REGISTER.md`. See that register for the specific doc corrections each row implies.
