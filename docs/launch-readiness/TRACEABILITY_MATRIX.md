## Coverage states

- **Automated baseline** — implementation exists and relevant automated checks
  are part of the current 2026-08-09 baseline. This does not replace UAT or
  deployed-environment evidence.
- **Partial** — implementation exists, but the QA plan identifies a browser,
  Worker, compatibility, security, performance, or manual evidence gap.
- **Conditional** — implementation exists only when its feature flag, role, or
  external provider is configured; acceptance applies only to an enabled
  deployment.
- **Required** — a quality requirement is defined but has no sufficient current
  execution evidence.

## Maintenance rule

Update this matrix in the same change whenever a capability, user-visible
behavior, authority boundary, persistence location, test ID, feature flag,
external integration, or support claim changes. A row may not be described as
accepted unless its current candidate has linked execution evidence for every
applicable QA and UAT gate. Preserve old release evidence separately instead of
rewriting history.
